# 03 · 手机端 UI 规格（Flutter）

> 本文件以 `prototype/voice-remote-mobile` 的实现为准。
> 原型：React + Vite + Tailwind，路由 `/m01`…`/m13` + `/components`，可运行、可交互。

## 1. 定位

手机是**遥控器 + 麦克风**，不是编辑器。

- 不显示历史列表，只保留"最近一条"。
- V1 不显示流式识别过程（设置里留了开关，默认关）。
- 90% 的操作只有一件事：按住、说话、松手。

## 4. 信息架构

```
/            画板索引（原型专用，不进正式 App）
/m01 欢迎 ──→ /m02 权限 ──→ /m03 搜索 ──→ /m04 扫码
                                  └────→ /m05 语音主屏
/m05 ──按住──→ /m06 收音 ──松手──→ /m07 识别 ──→ /m08 成功
                                          └────→ /m09 失败
/m05 ──上滑──→ /m10 控制面板（底部抽屉）
/m05 ──右上──→ /m11 设置 ──→ /m12 重连 / /m13 未连接
```

正式 App 的底部导航**不用 Tab Bar**，控制面板用底部抽屉，避免占用拇指区。

## 9. 文案规范

- 全中文，句子短，不用"请放心"这类空话。
- 失败文案 = 发生了什么 + 怎么办，≤ 18 字。
- 不出现技术词（AX、Opus、Bonjour）。
- 原型中的示例句可直接用于真机联调：
  - 「把第三段的标题改短一点，下面两行跟上节奏。」
  - 「周五下午两点前把方案发我，有问题随时找我。」
