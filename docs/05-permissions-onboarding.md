# 05 · 权限与授权引导

> 依据原型：手机 `M-02`，Mac `D-06`（设置·权限）与 `D-08`（首次向导第 2 步）。
> 前提：允许在 App 内引导用户去系统设置授权；macOS 不允许第三方 App 自行授予 TCC 权限。

## 1. 权限清单

### Mac 端

| 权限 | 何时需要 | 拒绝后果 | 检测 | 原型文案 |
|---|---|---|---|---|
| **辅助功能** | 核心：注入文本、切输入框 | 只能复制到剪贴板 | `AXIsProcessTrusted()` | 「把文字写进其他 App 的输入框」 |
| **输入监控** | 仅 B 后端：注入输入法语音键 | B 后端不可用，A 不受影响 | `IOHIDCheckAccess(.listenEvent)` | 「仅「输入法后端」需要，用于触发输入法语音键」 |
| **蓝牙** | 备用通道 | 只能走 Wi-Fi | `CBManager.authorization` | 「网络不通时用蓝牙传输语音」 |

不需要：屏幕录制、麦克风、完全磁盘访问、本地网络（macOS 13 无此项）。

### 手机端（M-02 三张卡）

| 权限 | 标注 | 说明文案 | 为什么 |
|---|---|---|---|
| 麦克风 | 必需 | 收音必需 | 不给权限，按钮按下去也没有声音。 |
| 本地网络 | 仅 iOS 需要 | 仅 iOS 需要 | 让手机在局域网里找到你的 Mac。 |
| 蓝牙 | 可跳过 | 可选，备用通道 | 网络不通时改走蓝牙，更稳。 |

Android 另需：通知（13+，前台服务可见）、前台服务（14+，麦克风类型）。安装即声明，不做引导页。

## 2. 引导原则

1. **情境化**：不在启动时一次要三个权限；Mac 向导是唯一例外（本来就是设置流程）。
2. **一次一个**：同一屏不弹两个系统弹窗。
3. **先解释再看弹窗**：卡片上先写"用来做什么"，再点授权。
4. **拒绝不是死路**：每个权限都有降级形态（见 §6）。
5. **可自查**：权限页永远能"重新检测"，不要求用户重启才知道结果。

## 3. Mac 端引导

### 3.1 首次向导第 2 步（D-08）

三张卡并排，复用权限页组件：

| 卡 | 状态示例 | 按钮 |
|---|---|---|
| 辅助功能 | 未授权 | 授权 |
| 输入监控 | 不需要（当前后端 A） | 授权 |
| 蓝牙 | 已关闭 | 开启 |

规则：

- **辅助功能未授权时，「下一步」置灰**。
- 其余两项允许跳过，进入第 3 步。
- 任何一步都可「稍后再说」；跳过后菜单栏图标转异常态，点击直达权限页。

### 3.2 权限页（D-06）

三张卡，每张 96 高，结构固定：

```
图标 + 权限名                    [已授权 ✓]
一句话说明
                        [打开系统设置]
▸ 为什么需要这个权限？
```

- 未授权：整卡浅黄底；已授权：白底 + 绿勾；需重启：黄底 + 「已授权，重启后生效」+「立即重启」。
- 状态 = 图标 + 文字，禁止只靠颜色。
- 展开"为什么"给 2–3 行白话，直接复用原型文案（见 `04-ui-mac.md` §6）。
- 底部固定一行：「授权后如果仍不生效，点这里重新检测」+「完成」。

### 3.3 重启策略（与原型有出入，按此实现）

原型三张卡都给了「立即重启」，实际只有输入监控需要：

| 权限 | 授权后 |
|---|---|
| 辅助功能 | 通常即时生效；3 秒内注入仍失败 → 显示「请重启 VoiceRelay」 |
| 输入监控 | **必须重启**，显示「已授权，重启后生效」+「立即重启」 |
| 蓝牙 | 即时生效，显示「重新检测」 |

### 3.4 状态刷新

- App 重新激活（`didBecomeActive`）时重测三项。
- 结果变化时就地更新卡片并写日志，不弹模态框。
- 检测到授权后 1 秒内更新 UI，不让用户手动点刷新。

## 4. 手机端引导（M-02）

- 顶部「第 2 步 / 共 3 步」+ 2/3 进度条。
- 卡片状态：待授权（琥珀）/ 已授权（绿底 + 勾）/ 已拒绝（玫瑰底 + 「设置 › 隐私 › 麦克风」+「去系统设置」）。
- 已授权后按钮变「撤销」，说明变「已开启，点右侧按钮可关闭」。
- 底部主按钮：麦克风未授权时置灰，文案改为「麦克风未授权，下一步不可用」。
- 底部提示：「拒了也没关系：去「设置 › 隐私」里可以重新打开，回来点一下就会变勾选态。」
- 原型右上角「全部允许（演示）」**正式版删除**。

## 5. 失败与边界

| 情况 | 表现 | 处理 |
|---|---|---|
| 勾了但仍不生效 | 「已授权，但检测失败」 | 「重启 App」+「重新检测」 |
| 重装/移动 App | TCC 记录失效 | 按未授权处理，不报错 |
| 系统升级重置权限 | 首次运行检测失败 | 自动跳权限页 |
| **Mac 受 MDM 管理** | 系统设置里看不到勾选项 | 显示「此权限由设备管理策略控制」，提示联系 IT，**不绕过** |
| 装了零信任/EDR | 本地监听被拦 | 提示"检测到安全软件可能拦截本地连接，可改用蓝牙通道" |

## 6. 降级形态

| 缺失 | 还能做什么 |
|---|---|
| 无辅助功能 | 识别照常，结果自动进剪贴板，提示「按 ⌘V 粘贴」 |
| 无输入监控 | A 后端完全可用，B 置灰 |
| 无蓝牙 | Wi-Fi 通道完全可用 |
| 手机无麦克风 | 无可用功能，停留在引导页 |
| 手机无本地网络（iOS） | 只能扫码直连，隐藏自动发现 |

## 7. 文案规范

| 位置 | 要求 | 示例 |
|---|---|---|
| 标题 | 只写权限名 | 「辅助功能」 |
| 一句话 | 说"用来做什么" | 「把文字写进其他 App 的输入框」 |
| 展开 | 讲清不授权会怎样 | 「没有它，识别出的字只能复制到剪贴板，需要你手动粘贴。」 |
| 按钮 | 动词开头 ≤ 5 字 | 「去授权」「重新检测」「立即重启」 |
| 禁止 | 空话与恐吓 | 不用"为了保证您的体验""请放心" |
