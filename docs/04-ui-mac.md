# 04 · Mac 端 UI 规格（SwiftUI）

> 本文件以 `prototype/voicerelay-mac` 的实现为准。
> 原型：8 个 HTML 规格页，覆盖 10 个画板 + 1 个组件页，每页可切浅色/深色并操作关键状态。

## 1. 定位

Mac 端是真正干活的一端，但用户几乎看不见它。UI 只解决三件事：

1. 让我知道连没连上、能不能用。
2. 让我把权限授了。
3. 出问题让我能看懂、能修。

不做主窗口、不做仪表盘、不做历史管理。

## 4. 菜单栏图标（D-01）

| 状态 | 图形 | 触发 | 行为 |
|---|---|---|---|
| 未连接 | 空心圆环 14 px，1.5 px 描边 | 无会话 | 点击展开弹窗，显示"等待手机连接"+ 配对码入口 |
| 已连接 | 实心圆环 | 握手完成、空闲 | 收音开始切三条竖线，松手回实心 < 300 ms |
| 收音中 | 三条竖线，高度 8/15/10，可跳动 | 正在接收音频 | 关闭动效时降级为静态三线 |
| 异常 | 圆环 + 右下 10 px 感叹号 | 权限缺失 / 后端不可用 / 连续失败 3 次 | **点击直接进设置 → 权限页，不经过弹窗** |

要求：状态切换 200 ms 交叉淡入；图标为 Template Image，不提供深色版资源。

## 5. 弹窗（D-02 / D-03 / D-04）

尺寸 320 × 420，从上到下五段：

| 区段 | 高度 | 内容 |
|---|---|---|
| 状态行 | 44 | 圆点 + 状态文字；右侧整行可点，展开连接详情 |
| 电平条 | 72 | 收音时动，空闲只留一条 2 px 静线，**不显示 0** |
| 最近文本 | flex | 最多 3 条，每条 2 行截断；点击复制；悬停 `···` 打开菜单：复制 / 重新注入 / 删除 |
| 底部状态栏 | 40 | 手机连接状态 + 后端下拉（A 本地 / B 输入法） |
| 底部操作栏 | 44 | 「设置…」「退出」 |

连接详情（状态行展开）：连接通道 `局域网 · 192.168.1.24`、延迟 `18 ms`、识别后端 `A · 本地`、模型 `已加载`。

三态差异：

| 态 | 差异 |
|---|---|
| D-02 已连接 | 圆点绿，电平静线，最近 3 条，底部「手机 已连接」 |
| D-03 收音中 | 圆点红 + 电平跳动，最近区可显示"正在听…" |
| D-04 未连接 | 圆点灰，顶部显示「等待手机连接」+ 6 位配对码 / 二维码入口，不显示过期文本 |

必须实现的两个确认弹窗：

1. 切后端：`切换到后端 B · 输入法？切换后需重新授权输入监控权限，正在输入的文本会中断。` → 取消 / 切换并重新检测。
2. 退出：`退出 VoiceRelay？手机将断开连接。` → 取消 / 仍然退出。

不抢焦点：打开弹窗、点击弹窗内任意按钮，前台输入框光标必须不动。

## 6. 设置窗口（D-05 / D-06 / D-07）

左 6 分区，右内容区，标题「VoiceRelay 设置」。

### 通用（D-05）

| 行 | 控件 | 说明文案 |
|---|---|---|
| 开机自启 | 开关 | 登录后自动驻留菜单栏 |
| 显示悬浮电平窗 | 开关 | 收音时在鼠标附近显示 140 × 44 电平窗 |
| 菜单栏图标样式 | 下拉 | Template Image，随系统自动反色 |
| 语言 | 下拉 | 当前版本仅提供中文 |
| 页脚 | 文字 | 这些设置随账号保存在本机，不上传。 |

### 连接

| 行 | 内容 |
|---|---|
| 当前设备 | `iPhone 15 Pro · 局域网 18 ms` + 已连接徽标 |
| 配对列表 | `2 台设备已配对，最近一次 14:31` + 管理 |
| 端口 | 只读 `0.0.0.0:8787` |
| 重新生成配对码 | 说明「新配对码用于新设备；已配对设备仍有效」+ 生成按钮 |
| 备用通道（蓝牙） | 开关 + 「网络不通时用蓝牙传输语音」 |

### 语音（D-07）

| 行 | 内容 |
|---|---|
| 后端选择 | A 本地识别 / B 输入法（未装虚拟声卡时置灰） |
| 模型选择 | 下拉：`SenseVoice Small（int8）· 约 230 MB`；体积以实际文件为准 |
| 灵敏度 | 滑杆，默认 62；「过低会漏掉轻声开头」 |
| 松手延迟 | 默认 180 ms |
| 最长录音 | 默认 60 秒 |
| 页脚提示 | 模型加载中时语音按钮禁用；延迟偏高时建议换更小模型 |

> 原型此处写的是 `Whisper Small · 约 466 MB`，与 D-02（sherpa-onnx + SenseVoice）冲突。**已裁决按 D-02 实现**，原型文案改为 `SenseVoice Small · 约 230 MB`，见 §11。

### 按键

| 行 | 内容 |
|---|---|
| App 切换 | 直接枚举、unhide、activate，必要时 open -b 强制置顶；覆盖所有正在运行的 App，不弹系统切换条 |
| 焦点切换回退 Tab | 开关 |
| 回车行为 | 下拉：不回车 / 回车 |

### 权限（D-06，全项目最重要的页面）

三张卡，每张高 96：

| 卡 | 说明 | 按钮 |
|---|---|---|
| 辅助功能 | 把文字写进其他 App 的输入框 | 打开系统设置 |
| 输入监控 | 为后续输入法语音键预留，当前版本不需要 | 打开系统设置 |
| 蓝牙 | 启用蓝牙备用通道时才需要 | 打开系统设置 |

状态规则：已授权（绿 + 勾）/ 当前不需要（灰色 + 减号）/ 未授权（浅黄底）。状态每 2 秒真实刷新。

要求：

- 状态 = 图标 + 文字，不只靠颜色。
- 每张卡下可展开「为什么需要这个权限？」，2–3 行白话，例：
  - 辅助功能：「VoiceRelay 需要把识别出的文字直接写进你正在用的 App……授权后就相当于你允许它代替你敲键盘。」
  - 输入监控：「当前后端 B 只写虚拟声卡，不会模拟输入法语音键，因此无需授权。」
  - 蓝牙：「公司网络或访客 Wi-Fi 常常禁止设备互访，这时只能靠蓝牙直连。」
- 底部固定：「授权后如果仍不生效，点这里重新检测」+「完成」。
- 不弹系统级模态框。

### 关于

版本、构建号、日志目录（`~/Library/Logs/VoiceRelay`）、导出诊断、开源许可。

## 7. 首次启动向导（D-08）

居中卡片 560 × 400，三步 + 完成/跳过两态。

| 步 | 内容 | 主按钮状态 |
|---|---|---|
| 1 | 「在手机装好 App，扫这个码」+ 二维码 + `voicerelay.local:8787` + 复制 | 下一步（可跳过） |
| 2 | 「授予三个权限」三张卡（复用权限页组件） | 辅助功能未授权时置灰 |
| 3 | 「试一句：按住手机上的按钮说句话」+ 信号 `-∞ dB` + 「模拟按住说话」 | **必须真的收到一次音频**才亮起"完成" |
| 完成 | 「可以开始用了」+ 「看看菜单栏图标」「打开弹窗」 | — |
| 跳过 | 菜单栏图标转为异常态，可「去授权」或「重新走一遍向导」 | — |

第 3 步失败时给三条排查：同一 Wi-Fi / 手机已连接 / 辅助功能已授权。

## 8. 悬浮电平窗（D-09）

| 项 | 值 |
|---|---|
| 尺寸 | 140 × 44，圆角 10 |
| 内容 | 5 根电平条 + 1 个红点 |
| 出现 | 收音收到电平时立即显示，受「显示悬浮电平窗」开关控制 |
| 消失 | 松手后 800 ms 淡出 |
| 位置 | 跟随鼠标，不接收鼠标事件 |
| 层级 | 浮动窗口，**不参与 Mission Control** |
| 交互 | 点击无动作，悬停不抢焦点，右键可关闭 |
| 硬要求 | 出现与消失都不能改变当前输入框光标位置 |

## 9. 异常态与降级（D-10）

| 场景 | 表现 | 恢复动作 |
|---|---|---|
| 权限被系统重置 | 图标转异常 + 弹窗顶部黄色横幅「需要授权才能使用」 | 去授权 / 复制诊断信息 |
| 手机未连接 | 「等待手机连接」+ 二维码入口 | 显示配对码 |
| 识别引擎未加载 | 状态行显示真实错误或「模型加载中」，不显示虚构百分比 | 等待或重试 |
| 注入失败 | 图标短暂变黄 + 系统通知「没有找到可输入的位置」 | 通知内说明先点输入框 |
| 虚拟声卡缺失 | 后端下拉 B 置灰，悬停「未安装虚拟声卡」 | 安装 pkg 或切回 A |

系统通知策略：失败发，成功不发；重连成功只更新状态。

## 10. 组件页（C-D）

权限卡 3 态、状态行 4 态、电平条、后端下拉、最近文本项、语义色板、字号与间距。

## 11. 原型修正记录（2026-11-26 已完成，实现按本文件）

| # | 原型现状 | 改为 | 原因 |
|---|---|---|---|
| 1 | 模型 `Whisper Small · 466 MB`、`占用约 420 MB 内存` | `SenseVoice Small（int8）· 约 230 MB` | D-02 已定 sherpa-onnx；Intel 上 Whisper 中文明显更慢 |
| 2 | 三张权限卡都写「立即重启」 | 辅助功能/蓝牙 → 「重新检测」；仅输入监控 → 「立即重启」 | 只有输入监控需要重启进程才生效 |
| 3 | 版本 `1.4.2 · 1420`、`18 ms`、`0.3 秒` | 真实版本号与实测值；无数据时显示「—」 | 原型假数据 |
| 5 | B 后端停流即显示成功、失败项显示“已复制” | B 显示「已发送到输入法·未确认」，失败显示「未送达」 | 与真实协议和注入结果一致 |
| 4 | 端口 `8787` | 保留（已是最终值） | 与 `02-protocol.md` 一致 |

原型已按本表修改；后续仍以 **本文件** 为准，两者再冲突时改原型。
